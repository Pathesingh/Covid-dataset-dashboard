# Covid-dataset-dashboard
About the Project
This project focuses on analyzing COVID-19 data to understand the spread, trends, and impact of the pandemic. I used data analytics and visualization techniques to convert raw data into meaningful insights that can help in better understanding patterns such as case growth, recovery rates, and mortality trends.

Created visualizations to make the data easy to understand
Identified key patterns and insights from the dataset.
